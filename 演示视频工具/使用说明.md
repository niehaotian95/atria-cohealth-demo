# 协同体检中心 · 演示视频工具

一键录制 demo 演示视频（约 90 秒，1280×720；录制 + 编码全程约 2 分钟）。

## 为什么需要这个工具

demo 本身是单文件 HTML（`Atria-协同体检中心-v31.html`，文件名随版本升级，取目录里版本号最大者），动态交互多（维度过滤、网络物理动画、对比模式、报告打字机）。视频能把完整故事一次讲清，方便发给不看代码的 stakeholders。

**v13 起自动巡览已内置主文件**：打开主文件 `Atria-协同体检中心-v31.html` 后点页面右上角「▶ 巡览演示」按钮即可播放。**不会加参数？最省事的做法是直接双击本目录的 `tour.html`**——它就是强制自动播放的副本，双击即播，不需要任何参数（在其上网址后追加 `?loop=1` 可循环播放，适合展会 / 触屏 kiosk）。想从主文件播放也可以：**在浏览器地址栏**（不是 Windows 资源管理器地址栏——资源管理器按文件路径解析，不认带 `?` 的查询串，粘上去多半打不开）打开主文件的完整 `file://` 网址，再在末尾加上 `?tour=1`，形如 `file:///D:/演示目录/Atria-协同体检中心-v31.html?tour=1`，回车即自动播放。

## 使用（两步）

1. 双击 `一键录制.cmd`
2. 等约 2 分钟（巡览约 90 秒 + 视频编码）。视频生成在工具包目录下：`Atria-协同体检中心-演示视频.webm`（**注意**：工具包自带的 ffmpeg 是精简版，只能输出 WebM/VP8；只有当本机另装了完整版 ffmpeg 支持系统 PATH 中可调时，才会输出 `…演示视频.mp4`）

## 环境要求

- **Node.js 22+**（自带的 WebSocket 用于连接浏览器调试协议）：https://nodejs.org/
- **Chrome 或 Edge**（自动查找，无需配置）
- 工具包内必须同时存在 `tour.html`、`record.js`、`ffmpeg.exe`

## 原理

1. 启动无头 Chrome/Edge 打开 `tour.html?tour=1`，浏览器以 1280×720 窗口渲染
2. `record.js` 通过 CDP（Chrome DevTools Protocol）以 30fps 截取 JPEG 帧，按真实时间轴对齐（截图慢于帧率时自动补帧，保证声画同步的时长准确）
3. 巡览播完时主文件输出 `TOUR_DONE` 信号，收到即停止截帧（兜底：96 秒）
4. 调用本目录 `ffmpeg.exe` 编码：有 libx264 输出 H264 MP4，否则输出 VP8 WebM
5. 清理临时帧图，保留最终视频

## 常见问题

- **端口被占**：脚本自动尝试 9922 / 9933 / 9944 / 9955 / 9966 / 9977
- **杀毒软件拦截 ffmpeg / 无头浏览器**：给本目录加白名单
- **视频打不开（双击 .webm 黑屏 / 提示无法播放）**：Windows 自带播放器对 WebM 的支持看运气。把 `Atria-协同体检中心-演示视频.webm` 直接**拖进 Chrome / Edge 窗口**即可播放；或在微软商店装「Web Media Extensions」后系统播放器也能放。想要 MP4：另装完整版 ffmpeg（带 libx264，装后在 PATH 中可调）后重新录一次（见上「使用」第 2 步，此时会自动输出 `…演示视频.mp4`）
- **想只看巡览不录像**：双击 `tour.html`（自动播放一遍）；或打开主文件 `Atria-协同体检中心-v31.html` 点右上角「▶ 巡览演示」
- **想手动操作 demo**：打开 `Atria-协同体检中心-v31.html`（原始版本，含全部交互；按 `?` 查看快捷键）
- **视频内容要改**：改主文件里 `sayTour("…")` 的字幕或时间间隔，在项目源码目录的 `.tmp_video/` 里跑 `node make-tour.js` 重新生成 tour.html，把产物复制到本目录，重新录制即可（该目录不在工具包内，仅存于开发环境）

## 文件清单

| 文件 | 说明 |

| `一键录制.cmd` | 启动入口 |
