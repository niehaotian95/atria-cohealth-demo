# 协同体检中心

> 代建制公共工程 · 跨组织协同诊断沙盘（Atria Demo 共建提交作品 · Field）
> 单文件、离线、零依赖——双击 `Atria-协同体检中心-v32.html` 即可运行

**一句话**：把「谁和谁卡在一起」变成一份可打印、可对比、可复盘的体检报告单。不是仪表盘，是体检中心。

## 60 秒上手

1. 下载 `Atria-协同体检中心-v32.html`，双击打开（Chrome / Edge / 任何现代浏览器，无需服务器）
2. 按 `?` 查看全部快捷键；按 `/` 搜索卡点；`Enter` 生成复盘报告；`P` 打印预览
3. 想看自动演示：双击 `演示视频工具/tour.html`，或在主文件地址后加 `?tour=1`（`?loop=1` 循环）

## 功能

- **五维协同体检**：权责清晰度 / 信息通畅度 / 审批效率 / 目标一致性 / 需求稳定性，印章评级 + 复查同比
- **卡点分诊台**：按风险分级，每张卡含现象 / 证据 / 处方 / 责任主体，点击归因到维度
- **跨组织关系网络**：8 个参与主体、12 条协同关系，连线颜色即健康度，点击出诊断面板
- **六阶段时间轴** + 当前进度标记，点击阶段高亮参与主体
- **五场景对比**：医院 / 轨道 / 排水 / 学校 / 水厂，五维并排找可迁移的标准动作
- **四种交付口径**：打印报告单（A4 友好）/ 屏幕报告（打字机生成）/ Markdown 下载 / 9 幕自动巡览
