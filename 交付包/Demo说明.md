# 协同体检中心 · Demo说明

> **作品名称**：协同体检中心（Atria-协同体检中心-v32）
> **命名格式**：[Atria Demo共建] 协同体检中心 - Field
> **源码与相关文件**：见邮件所附 GitHub 仓库（主文件 / 巡览版 / 演示视频工具箱 / 视频渲染管线 / 校验器 / 迭代记录）；本压缩包仅含 Demo说明.md 与演示视频。
> **一句话创意**：把公共工程代建制里最说不清的「谁和谁卡在一起」这件事，做成一份**可打印、可对比、可复盘的协同体检报告单**。不是仪表盘，是体检中心。

---

## 一、创意来源

公共工程「代建制」的痛点不是缺数据，而是**跨组织协同没有诊断口径**：权责边界模糊、信息口径偏差、审批串联时序……这些问题散落在例会纪要、周报、月报里，没有地方被**结构化地指认**。

领导问「为什么又卡住了」，得到的总是讲故事而不是讲指标。

协同体检中心把五块「协同 Commons」拆成可量化的五维体检指标，像医院分诊一样：**先体检打分，再分诊归因，最后开出处方**，并把结论固化为跨场景可迁移的标准动作。

## 二、主要功能

### 1. 五维协同体检（核心面板）
- 五维评分：权责清晰度 / 信息通畅度 / 审批效率 / 目标一致性 / 需求稳定性
- 综合评分映射评级（A 优 / B 良 / C 中 / D 弱，带**印章**与**报告编号**）
- **复查同比**：每维对照上期体检打分，▲▼ 涨跌一眼可见

### 2. 卡点分诊台
- 卡点按**高/中风险**分诊成组（不是平铺清单）
- 每张卡点含：**现象描述 / 证据 / 干预处方 / 责任主体**
- 点击卡点 → **归因 chip 直达对应维度**（卡点与维度一一对应）

### 3. 跨组织关系网络
- 节点为参与主体（代建办 / 卫健委 / 院方 / 审批部门 / 设计院 / EPC / 监理 / 审计）
- **连线颜色 = 协同健康度**（绿 ≥79 平稳 / 蓝 65–78 尚稳 / 红 <65 薄弱）
- 点击主体 → 右侧诊断面板给出角色、高频动作、短板
- 风险速览「最薄弱关系」一键定位，**窄屏下自动滚向详情而非画布**

### 4. 六阶段协同时间轴
- 前期立项 → 勘察设计 → 招标采购 → 施工实施 → 竣工验收 → 移交使用
- 红色「当前 N%」虚线标记项目进度，**虚线走在标签背后不压字**
- 点击阶段节点 → 网络中高亮该阶段参与主体

### 5. 场景对比与复盘
- 5 个虚构场景（医院 / 轨道 / 排水 / 学校 / 水厂）一键切换
- **对比模式**：两个场景五维并排，找出「能迁移的标准动作」
- 一键生成七节结构复盘报告（含 30 天干预时间线）

### 6. 四种交付口径（同一份体检）
- 📄 **打印报告单**：A4 友好，徽章在默认打印设置下不消失（深色主题下自动反白）
- 🖥 **屏幕报告**：打字机逐行生成，可中断、可点击直达
- ⬇ **Markdown 下载**：七节同源同序，粘贴进文档系统
- 🎬 **巡览演示**：9 幕自动巡览，`?tour=1` 自动播放 / `?loop=1` 循环

### 7. 演示视频工具箱（附赠）
- `tour.html`：双击即自动播放的巡览版（不需要服务器）
- `一键录制.cmd` + `record.js`：CDP + ffmpeg 自动录制 WebM（含 `TOUR_DONE` 收尾信号）
- `使用说明.md`：给非技术人员的分步操作指引

## 三、使用方式

### 最快路径
1. 从 GitHub 仓库取 `Atria-协同体检中心-v32.html`，双击打开（单文件、离线、零依赖）
2. （可选）按 `?` 键查看全部快捷键
3. 想要演示模式：在文件路径后加 `?tour=1`，或直接双击仓库 `演示视频工具/` 里的 `tour.html`

### 键盘速查
| 键 | 作用 |
|---|---|
| `?` | 快捷键帮助 |
| `/` | 搜索卡点 |
| `↑ ↓ ← →` | 聚焦画布后移动/选中（方向键需先点画布） |
| `+ − 0` | 缩放/复位（需先聚焦画布） |
| `Enter` | 生成复盘报告 |
| `Esc` | 中断打字 / 清除选中 / 退出对比待选 |
| `P` | 打印预览 |

### 数据
- 全部为**虚构示例数据**（报告页与数据面板明示「示例数据」标记，不留误导）
- 「查看 / 编辑当前数据」可直接改 JSON，改完与未改可区分；导入数据前有**应用/放弃**确认
- 切换顶部「场景预设」= 换一个项目，五维/网络/卡点全部重算

## 四、工程指标

- **校验断言 437 项，0 失败**（JS 结构 + 运行时行为 + 文案一致性三层）
- 单文件、离线、零依赖（纯 HTML/CSS/JS，无构建步骤）
- **三轮挑刺闭环 15 轮**：viewer-critic 只读通读 → 修复工匠改版 → 校验器钉死回归（迭代记录见 `iteration-log.md`）
- 敏捷响应式：窄屏（≤920px）单栏布局，时间轴标签在 ≤640px 下错开密度点

## 五、诚实声明

- 演示视频由**节目式逐帧渲染管线**生成（沙箱无浏览器，无法真机录屏）：8 幕 × 10 秒，数据实时取自 v32 源码
- 打印件色彩、深色模式打印纸面、巡览真实节奏等仍需在真实浏览器中人工确认（清单见 `iteration-log.md`「仍需人工确认」一节）
- 全部项目数据均为虚构，仅作演示用途
